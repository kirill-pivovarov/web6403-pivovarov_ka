## Лабораторная работа №4

### Выполненные задания

В рамках лабораторной работы был модернизирован сайт PaintRent, разработанный в лабораторной работе №2. Добавлены новые элементы интерфейса и функциональность с использованием современных возможностей CSS и JavaScript.

**1. Современная CSS-вёрстка**
- Использована технология Flexbox для организации расположения элементов страницы.
- Использована технология CSS Grid для создания сеточных макетов.
- Все цвета оформления вынесены в CSS-переменные (`:root`), что упрощает управление цветовой схемой сайта.

**2. CSS-анимация**
- Реализована анимация появления элементов интерфейса.
- Добавлена анимация успешной отправки формы авторизации.
- При отправке формы карточка авторизации плавно трансформируется в сообщение «Вы успешно зарегистрировались».
- Для создания анимации использованы `@keyframes`, `transform`, `opacity`, `filter`, а также SVG-анимация прорисовки окружности и галочки.

**3. Страница авторизации**
- Создана новая страница `login.html`.
- Разработана форма авторизации, включающая поля:
  - Email;
  - Пароль;
  - Роль пользователя (Client или Partner).
- Добавлена проверка корректности заполнения полей средствами HTML и JavaScript.
- Реализована адаптивная вёрстка страницы.

**4. Объектно-ориентированное программирование на JavaScript**
- Создан класс `User` с конструктором для хранения введённых данных пользователя.
- Реализован метод `printInfo()` для форматированного вывода информации о пользователе в консоль.
- При отправке формы создаётся экземпляр класса `User`, после чего вызывается метод вывода информации.
