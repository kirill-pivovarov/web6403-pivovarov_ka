## Выполненные задачи (Лабораторная работа №2)

* **Разработка структуры страниц**: Сверстаны и интегрированы ключевые страницы веб-приложения (`index.html`, `cart.html`, `profile.html`, `painting.html`).
* **Дизайн-система и темная тема**: Настроена централизованная архитектура стилей на CSS-переменных, реализована темная тема с акцентными золотыми элементами и эффектами стекломорфизма (`backdrop-filter`).
* **Макет и адаптивность (Layout)**:
  * Настроена шапка сайта (хедер) с помощью Flexbox: логотип слева, панель поиска по центру, иконки корзины и профиля справа.
  * Исправлено позиционирование футера (`min-height: 100vh` для `body` и `flex: 1` для основного контента), обеспечивающее корректный прижим футера к низу экрана.
  * Устранено подчеркивание текста у ссылок-карточек и скорректировано отображение полей ввода даты.
* **Компоненты и таблицы**:
  * Создана страница личного кабинета пользователя (`profile.html`), содержащая блок статистики и адаптивную **таблицу истории заказов и аренды**.
  * Оптимизированы карточки товаров с табами аренды и покупки.
